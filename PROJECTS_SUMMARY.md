3. **Cross-Platform PWA Installation**: Native web application support (`apple-mobile-web-app-capable`) allowing installation directly onto home screens like a mobile app.
4. **Firebase Auth & Adaptive Theme System**: Secure user authentication with persistent theme preference detection (`max-ai-theme`).
